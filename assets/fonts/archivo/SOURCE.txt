Source: google/fonts ofl/archivo/Archivo[wdth,wght].ttf, font version 2.001
        (upstream Omnibus-Type/Archivo b5d63988ce19), sha256
        0e094a7d3c7c4c25cf1310c4b30014f1dae9332220b1c2c88f4fa996f0b05053.
        The web panel serves the same version (wwwroot/lib/fonts/archivo/*.woff2).

Build (fontTools 4.60.2), per weight 400 / 500 / 600 / 700 / 800:
  1. varLib.instancer.instantiateVariableFont(font, {wght: W, wdth: 100}, updateFontNames=True);
     OS/2 usWeightClass = W, usWidthClass = 5; DSIG dropped; PostScript name Archivo-<Style>.
  2. subset.Subsetter with layout_features='*' (tnum, case, locl TRK, kern, mark … all kept),
     every script and name record, unicodes present in the font from:
     U+0020-007E U+00A0-00FF U+0100-024F U+0250-02FF U+0300-036F U+1E00-1EFF U+2000-209F
     U+20A0-20CF (₺ U+20BA, €) U+2100-218F U+2190-22FF U+2500-25FF U+FEFF U+FFFD.
Files: Archivo-Regular / -Medium / -SemiBold / -Bold / -ExtraBold.ttf (Flutter needs static TTFs).

The family name lives in one place: AknFonts.sans (lib/core/ui/typography.dart) + the pubspec
`fonts:` entry. To go back to Plus Jakarta Sans, restore assets/fonts/jakarta/ from design-v3
commit 77dfa2b and point both at it.
